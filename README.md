## 📋 Completed Tasks

### Task 1: Term Deposit Subscription Prediction

* **Objective:** Predict whether a bank customer will subscribe to a term deposit based on marketing campaign data.
* **Approach:** Conducted data exploration and categorical feature encoding. Trained classification models (Logistic Regression, Random Forest) and evaluated performance using Confusion Matrices and ROC Curves. Implemented SHAP/LIME for model interpretability.

### Task 2: Customer Segmentation

* **Objective:** Cluster customers by spending habits to propose tailored marketing strategies.
* **Approach:** Performed Exploratory Data Analysis (EDA). Applied K-Means Clustering for segmentation and used PCA/t-SNE for dimensionality reduction and cluster visualization.

### Task 3: Energy Consumption Time Series Forecasting

* **Objective:** Forecast short-term household energy usage based on historical patterns.
* **Approach:** Parsed and resampled time series data with engineered time-based features. Compared performance across ARIMA, Prophet, and XGBoost models, using MAE and RMSE for evaluation.

### Task 4: Loan Default Risk Optimization

* **Objective:** Predict loan default likelihood and optimize decision thresholds for cost reduction.
* **Approach:** Cleaned and preprocessed financial datasets. Trained binary classification models and performed a business cost-benefit analysis to adjust the threshold for minimizing false positives and negatives.

### Task 5: Interactive Business Dashboard

* **Objective:** Develop an interactive dashboard to analyze sales, profit, and segment-wise performance.
* **Approach:** Cleaned global superstore data and built a Streamlit application. Integrated interactive filters (Region, Category) and displayed key performance indicators (KPIs) such as Total Sales and Profit.
